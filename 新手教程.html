1先确认你用的是 Chrome 或 Edge

别的浏览器也能用，但这两家最省事。

在浏览器右上角找「三个点」菜单 → 设置 → 关于，第一行就写着浏览器名字和版本。版本 100 以上就行，不用管具体数字。

页面能正常打开 PTA、能登录、能看到题目 —— 这一条就够了。

用 Firefox 也行，只是装油猴要去它自己的插件站，下面两个商店链接对你不适用。

如果点猴子图标毫无反应、或者菜单里一片空白 —— 说明扩展被浏览器禁用了，去 chrome://extensions（Edge 是 edge://extensions）把它打开。

4打开 PTA 的编程题页面

必须是「能填代码」的那一页。

登录 PTA → 进入你的作业/考试 → 左边题目列表里点函数题 / 编程题。判断标准很简单：页面右边有一个黑色的代码编辑框，框里可能已经有一段灰色模板。

右下角（或右上角）自动弹出一块紫色面板，标题写着「PTA 逐字输入」。
面板没弹出来？先把这一页刷新一次（F5）。还是不出来就看下面「出问题怎么办」第 3 条。

注意：选择题、填空题页面不会弹面板 —— 那些题用不着敲代码，这个脚本也不管它们。

5用面板把代码「敲」进去

就三下：粘、点、等。

  1. 把你的代码粘进面板里那个大框（不是右边 PTA 的框，是面板里的框）。在面板里按 Ctrl+V 或右键粘贴都行 —— 这个框是我们自己的，PTA 的禁粘贴拦不到。
  2. 速度保持默认的 快（8ms） 就可以。想看着它慢慢敲，选 正常（30ms）。
  3. 点 「敲进去」（或者在面板里按 Ctrl+Enter）。

面板上每个东西是干什么的

大框
放代码的地方。粘贴只往这里粘。
速度
每个字符之间隔多久。极快=瞬间、快=8ms、正常=30ms、慢=100ms。
敲进去
开始写。会先清空 PTA 的代码框，再从第一个字符写起。
停下
中途想中断就点它，已写进去的会留在那儿。
读一下
读出 PTA 代码框里现在到底是几个字符、走的是哪条通道。核对用。
清空
只清面板里的大框，不动 PTA 的代码框。
状态行
绿色 ✓ = 写完了；红色 ❌ = 没写成，后面会告诉你原因。
面板挡住题目
按住面板顶部标题栏可以把它拖到别处；点 × 关掉后，点右下角「⌨ 逐字输入」能再叫出来。
PTA 右边的代码框里出现了你的代码，缩进和换行都对；面板状态行变成绿色的「✅ … 个字符全部写入」。
写完先看一眼代码框第 1 行，Python 的缩进错一个空格就会报错。不放心就点「读一下」，它会告诉你框里现在有多少字符。

6自己点「提交本题作答」

这一步脚本绝对不会替你做。

确认代码没问题，自己点页面上的 「运行测试」 先跑一遍样例，通过了再点 「提交本题作答」。

这个脚本一行提交代码都没有。它只会往编辑框里写字，不会点保存、提交、交卷、结束考试里的任何按钮 —— 你自己看了再交。

7方案 B：不装油猴，用 exe（哇嘞哇嘞大雷猪）

双击 哇嘞哇嘞大雷猪.exe 就有窗口，不用装任何扩展，也不用换浏览器。

这软件是干什么的
把代码一个字一个字敲进 PTA 的代码框。敲的是真实按键，不是粘贴，所以 PTA 的「禁止粘贴」拦不到。
不联网 · 不读剪贴板 · 不替你点任何按钮 —— 题目还是你自己提交。

第一次打开可能会被 Windows 拦一下：屏幕出现蓝色的「Windows 已保护你的电脑」。点左边那行小字 「更多信息」，再点 「仍要运行」。这是因为它会模拟键盘，被杀毒软件当成可疑程序了 —— 它不联网、不读文件，代码全在同一个 exe 里。

  1. 双击 exe。代码可以粘进上面那个黑框（Ctrl+V 没问题，这个框是它自己的，不禁粘贴），也可以什么都不粘 —— 只要你先复制好了，点「开始敲」时它会自己从剪贴板取
  2. 浏览器打开 PTA 那道编程题，用鼠标点一下右边黑色代码框，让光标在里面闪
  3. 回 exe，点紫色的 「开始敲」，弹的确认框点「确定」
  4. 倒计时结束前切到浏览器（秒数自己调，默认 3 秒），然后手离开键盘和鼠标，看着它一个字一个字打进去
  5. 打完了自己点「运行测试」→「提交本题作答」
忘了怎么用就点右上角那个紫色的 ?，四步用法写在那儿 —— 所以只发这一个 exe 也够，不用配说明书。
切回浏览器后，能看到代码框里以大约每字 8 毫秒的速度正在被填写；exe 底部状态变成绿色的「✅ 全部敲完」。
它会检查最前面的窗口是不是浏览器。如果当时最前面是游戏、微信、终端之类，它会直接取消并告诉你「一个字都没发出去」—— 这是保险，别绕过它。真要敲，就先把浏览器切到最前面。
敲的过程中别碰键盘鼠标。它是在模拟真实的按键，此刻你按的任何键也会一起进到代码框里，代码就乱了。要中途停，就点 exe 上的「停止」——已经敲进去的部分会留着，不会自动撤销。
代码里如果有 制表符（Tab），程序会先提醒你。有些编辑器把 Tab 当成「切换焦点」，一按下去光标就跑了，后面的字会全部打飞。遇到提醒就点「取消」，把 Tab 换成 4 个空格再来。

窗口默认是「置顶」的，也就是它会一直浮在浏览器上面，方便你边看代码边敲。觉得挡事就把 「置顶」那个勾去掉（或按 Ctrl+T 切换），它会乖乖缩到后面去。关掉再打开时，位置、大小和置顶状态都记得住。

倒计时秒数也能自己改。控制条上有个 「等待 [3] 秒」，就是点「开始敲」之后给你多少秒切到浏览器。手快的调到 1 秒，要慢慢找代码框的调到 10 秒，填 0 就完全不倒数（先把光标点好再点「开始敲」）。这个数字关掉再开也记得住。

如果觉得字发灰、笔画粘连，或者窗口小得可怜 —— 那是 1.2.0 及更早版本在高分屏（125% / 150% 缩放）上的毛病：程序没声明自己是「DPI 感知」的，Windows 就把它当老程序，先按 96 DPI 画一遍再把整张图放大。1.2.1 已修，换成新 exe 就好；旧配置文件里的窗口大小会在启动时按当前 DPI 自动放大一档，你拖过的位置不变。
如果敲出来的缩进变成双倍（`def f():` 下面那行空了 8 格而不是 4 格）—— 那是 PTA 的代码框自己在按 Enter 后补了缩进，老版本又照着你的原文再敲一遍。1.2.2 已修：每次换行后先把编辑器补的那段删掉再照原文敲。别用 1.2.1 及更早的旧 exe。
1.3.0 又加了个「PTA 模式」（默认开着，控制条上那个勾）。既然网页已经白送了缩进，就不用再敲一遍：程序先算下一行原文有几个空格、再预测编辑器会给几个，两个数一样就跳过原文那几个空格，直接接着敲正文；不一样就退回老办法，删掉编辑器给的照原文敲。两种结果都对，前者省按键 —— 183 个字符的样例省了 32 个空格。顺便还处理了 PTA 的括号自动补全（敲 ( 会自己补 )），不然 `x = [` 回车会多出一行收尾括号。
1.3.1 修了一个会静默写坏代码的问题，值得单独说一下。1.3.0 的 PTA 模式以为「普通语句按 Enter 之后编辑器会把缩进退回去」，所以把这种行预测成 0 格。实际上 PTA 的代码框从不反缩进：在 def f(): 里面敲完一行 return 1 再回车，新行还是 4 格。于是
def f():
    return 1
x = 2
敲出来会变成 x = 2 也缩进 4 格 —— 粘进编辑器里看不出错，运行才报 IndentationError。现在规则改成「非块头的行一律保持和上一行一样深」，只有 def / if / for / while / with / try / class 这类块头才 +4 格；else: / elif / except / finally 这四种网页行为实测不一致（顶格 else: 给 4 格、顶格 except: 给 0 格），程序干脆不猜，直接走「删掉重敲」。总之不管哪条路，写进去的都是你原文的样子。

exe 版本和油猴版本的区别：exe 打的是「当前最前面的窗口」，所以它必须靠你先把光标放进代码框；油猴版本是直接写进 PTA 的编辑器，不需要点，也不会打错地方。

i它到底是怎么做到的（一句话版）

PTA 的「禁止粘贴」拦的是粘贴这个动作（paste 事件和剪贴板数据）。这个脚本压根不碰剪贴板：它通过编辑器自己的接口（CodeMirror 的 dispatch）、浏览器的编辑命令（execCommand）、以及最原始的直接赋值，把字符一个接一个放进代码框里。这三条路都不产生粘贴事件，所以禁令拦不到它。

顺带说一句：浏览器不允许网页伪造「真实的键盘按键」，所以做不到真正意义上的模拟键盘 —— 但这不重要，结果是代码确实出现在了框里。

它明确不会做的事
  • 不联网。整个脚本没有一处网络请求，同学电脑上不用装任何服务
  • 不读你的题目、不识别你的考试、不上传任何东西
  • 不点保存、不点提交、不点交卷、不点结束考试
  • 不会碰 PTA 的登录状态和 cookie

遇到查不到的情况，把面板状态行那行字发回来（截图最好）。

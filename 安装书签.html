装一个书签就够了

不用装扩展、不用装软件、不用管理员权限。整个工具就是一个书签。

1把书签栏打开

按 CtrlShiftB。浏览器上方会多出一条横栏，那就是书签栏。

看到浏览器上方出现一条横栏（或者本来就有书签）—— 这一步就成了。

2把下面这个紫色按钮拖到书签栏上

按住它别松手，拖到刚才那条横栏上，然后松手。

写代码

拖完之后，书签栏里会多出一个书签。名字随便改（双击它，或右键 → 修改），名字不影响功能。

拖动的时候鼠标要一直按着，拖到书签栏上再松手。松手早了会变成「打开这个链接」，那就再拖一次。

复制后：Ctrl+Shift+O 打开书签管理器 → 右上「⋮」→ 添加新书签 → 名称随便填，网址粘进去 → 保存
书签栏里出现了那个书签 —— 装完了，以后不用再回来这个页面。

3用：打开 PTA 题目 → 点书签 → 粘代码 → 回车

在 PTA 的编程题页面上，点一下书签栏里那个书签，会弹出一个紫色的面板。
把代码粘进面板里（CtrlV，这个面板是自己的，不禁粘贴），按 CtrlEnter。

面板底部出现绿色的「✓ 已写入 N 个字符」，右边代码框里就是你的代码了，缩进和换行都对。
它只往代码框里写字。不会点保存、不会点提交、不会点交卷。写完你自己看一眼，自己点「运行测试」和「提交本题作答」。

?几个要知道的

  • 为什么这个不算「粘贴」：它直接用编辑器自己的接口把文字放进去（CodeMirror 的 dispatch），根本不产生粘贴事件。实测过：往这个代码框里派一个真的 paste 事件，PTA 会把它 preventDefault 掉、一个字都进不去 —— 所以只能走这条路。
  • 再点一次书签会关掉面板，按 Esc 或点面板外的灰色区域也能关。
  • 会覆盖代码框里原有的内容，不是往后追加 —— 想换一版就直接再写一次。
  • 只对能写代码的题有用（函数题 / 编程题）。选择题、填空题点书签会提示「没找到代码框」。
  • 换电脑怎么办：书签跟着浏览器账号同步（登录 Chrome / Edge 账号就会同步过去）；没同步就把这个页面拷过去再拖一次。
你看到的怎么办
拖不动，或者拖上去没反应用上面「拖不动？点这里复制」，然后照提示手动加一个书签
点书签没任何反应确认点的是书签栏里的那个书签，不是这个页面上的按钮
提示「没找到代码框」当前不是编程题，或者题目还在加载。等一秒再点
提示「写进去了但读回来对不上」自己看一眼右边代码框，缺什么补什么。这种情况很少见

i它到底是什么

一个「书签」而已。普通书签存的是网址，这个存的是一小段代码。点它的时候浏览器就在当前页面上执行这段代码 —— 所以你不需要装任何扩展，也不需要运行任何 exe。

全部代码都在这个书签里，不联网、不上传、不读你的题目、不碰别的网站。图标来自 Lucide 开源图标库（ISC 许可），内联在页面里，不加载任何外部资源。
